# Contributing

This template follows the [Mastra monorepo contribution guide](https://github.com/mastra-ai/mastra/blob/main/CONTRIBUTING.md). Discuss a feature request and wait for maintainer acceptance before opening a pull request. A pull request must link its accepted issue.

Changes to this template belong under `templates/template-fxmacrodata-research` in the monorepo, rather than an automatically synchronized template mirror.
